
# DEV HEROES

DEV HEROES é um RPG educacional criado para ensinar programação através de exploração, missões, desafios e progressão de personagem.

O projeto utiliza conceitos de gamificação para transformar o aprendizado de tecnologia em uma aventura interativa.

## Objetivo

Permitir que estudantes aprendam programação de forma divertida e prática.
